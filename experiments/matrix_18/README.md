# 18 条对照任务

这是任务清单与历史 A 对照数据，不是新的模型或结果矩阵。`selection_18.json` 固定 18 个任务身份；`data/` 是同一批任务的 Habitat 数据视图；`a_18_results.json` 和 `a_18_summary.json` 是从已完成的 120 条 A 组结果中按身份抽出的记录。`prepare.py` 用固定种子 20261103 选择每类 3 条，选择时不读取成功结果，并核对任务内容和历史身份。

`parser_audit.md` 描述 frontier 评分的模型输出：模型看到带 A、B 等标签的画面，返回类似 `{"A": [0.3, "理由"]}` 的文字，程序需要把它读成 JSON，才能使用概率。解析失败和重试影响时间与调用量，因此需要作为实验指标；本文件不改变解析器。

后续 B/C/D 要在这份任务视图上运行，再比较 A 和新模型对应策略。当前本目录没有 B/C/D/A′/D′ 的正式结果，也没有自动启动它们。
